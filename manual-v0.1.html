🌟 LA REGLA DE ORO (Tu mantra diario)

¿Algo va mal? No entres en pánico.

  1. APARTA el producto rebelde (a un lateral, sin bloquear el flujo).
  2. SIGUE trabajando con el siguiente (el flujo es sagrado).
  3. REVISA lo apartado cuando el ritmo baje (en momentos de baja carga).

  • Impresora: ¿Número coincide con escáner? ¿Papel?
  • Suministros: ¿Rollos de repuesto? ¿Bolígrafo?

🔴 CATEGORÍA ROJA – Problemas físicos de carga

"Calidad antes que velocidad (pero con ritmo de campeón)"

PENDIENTE DE VALIDACIÓN OFICIAL

Cargar un RCG o pallet es como jugar al Tetris en la vida real.

🏆 Lo que SÍ se hace

  • Maestro del Tetris: RCG con cajas encajadas, sin huecos.
  • Pallet de Krats de Élite: Alineados, etiquetas fuera.
  • Armado mixto: Base pesada abajo, tuberías laterales, ligeras arriba.

🟢 CATEGORÍA VERDE (Parte 1) – Ingreso de productos

Usa Smart Scanner cuando el escáner dice "NOT FOUND" o "SSCC number is wrong or missing". PENDIENTE DE VALIDACIÓN OFICIAL

Método INBOUND

  1. Escanea código inferior (SSCC)
  2. Elige tipo (KRT, COL…)
  3. Si dice "NOT FOUND" → SURPLUS

Método SURPLUS

  1. Cambia a modo SURPLUS
  2. Escanea código inferior + código superior (cliente)
  3. Si dice "ANOTHER POSITION" → vuelve a INBOUND

🟢 CATEGORÍA VERDE (Parte 2) – Etiquetas, impresora y cierre

PENDIENTE DE VALIDACIÓN OFICIAL

📋 PROTOCOLO A – Recuperar LPN

Solo si tienes producto escaneado (pantalla pide LPN destino).

  1. Blue Yonder → ... → CHANGE POSITION
  2. Flecha abajo → aparece LPN
  3. Anótalo en papel
  4. Smart Scanner → PRINTING → tu impresora → LPN PRINTING → código manual

📋 PROTOCOLO C – Stickers de cierre

Para RCG/pallet ya cerrado sin stickers.

  1. Smart Scanner → PRINTING → SSCC INTERGAMMA
  2. Imprime 2 copias
  3. Pega: frontal + junto al LPN original. En krats: entre los krats

🟠 CATEGORÍA NARANJA – Emergencias y errores humanos

PENDIENTE DE VALIDACIÓN OFICIAL: En emergencia real, sigue protocolos oficiales de DHL.

🎨 Derrame de pintura o líquido

  1. El flujo NO se detiene
  2. Kit de emergencia (arena) → espárcela
  3. Limpia de afuera hacia adentro
  4. Residuos en contenedores especiales
  5. Informa a Teamleader o Troubleshooter

❌ Confusión de contenedor

  • Síntoma: LPN escaneado no corresponde al destino
  • Acción: Verificar destino, comparar números, reubicar
  • Si es patrón repetido → informar a Teamleaders

❌ Escanear sin colocar

  • Consecuencia: Sistema registra como colocado (no lo está)
  • Prevención: Nunca escanees sin colocar
  • Si ocurrió: intenta colocar; si no, informa a Teamleaders

👀 Producto mal ubicado

  1. Escanea para ver destino
  2. Colócalo donde indique (si se puede)
  3. Si no: INVENTORY DSP
  4. Si en suelo: inventory dsp
  5. Patrón repetido → informa a Teamleaders
